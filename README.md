# Transport Safety Data Analysis

## About the Project

This project examines people's perceptions of safety across different transport modes and road conditions.

The analysis was carried out using R and is based on a transport safety dataset containing information about transport modes, road conditions, traffic, and personal characteristics.

## Objectives

The project aims to:

- Examine perceived safety across different transport modes.
- Compare perceived safety between males and females.
- Examine the effect of road and traffic conditions on perceived safety.
- Identify factors associated with perceived safety.
- Present the findings using clear charts and statistical analysis.

## Data

The project contains two datasets:

- `rating_safety.csv` – Original dataset.
- `cleaned_transport_safety_data.csv` – Dataset prepared for analysis.

## Analysis

The project includes:

- Data cleaning
- Descriptive analysis
- Data visualization
- Comparison of transport modes
- Comparison by gender
- Correlation analysis
- Statistical testing
- Regression analysis

## Main Findings

The analysis found differences in perceived safety between several transport modes and road conditions.

The regression analysis showed that the factors included in the model explained about **36.3% of the variation in perceived safety**.

Road conditions, transport mode, gender, and some age groups were among the factors associated with perceived safety.
